# Supplier Evaluation Scorecard

Completed scorecards are saved in `confidential/suppliers/` and referenced only by ID (e.g., `SUP-A`).

| Criterion | Weight | Score (1–5) | Weighted | Evidence / notes |
|-----------|-------:|:-----------:|---------:|------------------|
| Quality and lab-test history | 30% | | | Certificates of analysis, sample test results |
| Food-safety certifications / documentation | 20% | | | Certifications, FDA registration, FSVP readiness |
| Capacity and scalability | 15% | | | Annual volume, ability to reach 3× |
| Price and payment terms | 15% | | | FOB price, MOQ, deposit terms |
| Lead time and reliability | 10% | | | Quoted vs. actual on samples |
| Ethical / sustainability practices | 10% | | | Grower relationships, labor practices |
| **Total** | **100%** | | | |

**Qualification threshold:** total of 3.5 or higher, and no criterion below 2.

## Scoring Guide

| Score | Meaning |
|------:|---------|
| 5 | Exceeds requirements, with documented evidence |
| 4 | Meets requirements, with documented evidence |
| 3 | Meets requirements; evidence partial |
| 2 | Gaps that can be fixed within 3 months |
| 1 | Doesn't meet requirements / no evidence |
